SETUP: 4 EASY STEPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. GET API KEYS (5 min)
   ✓ Amadeus: https://developers.amadeus.com/register
   ✓ Kiwi.com: https://tequila.kiwi.com/
   ✓ Gmail app password: https://myaccount.google.com/apppasswords

2. ADD GITHUB SECRETS (3 min)
   Go: Settings → Secrets and variables → Actions
   Add 5 secrets:
     • AMADEUS_CLIENT_ID
     • AMADEUS_CLIENT_SECRET
     • KIWI_API_KEY
     • EMAIL_USER
     • EMAIL_PASSWORD

3. ENABLE GITHUB PAGES (2 min)
   Go: Settings → Pages
   Source: GitHub Actions

4. RUN FIRST WORKFLOW (30 sec)
   Go: Actions → Flight Deal Tracker → Run workflow
   Wait 2-5 minutes for first run.
