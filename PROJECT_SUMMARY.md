# Flight Deal Tracker - Project Summary

## ✅ What You Have

A complete, production-ready flight deal tracker system for your June 2026 trip.

---

## 🎯 Core Features Implemented

### 1. **Multi-Source Flight Search**
- **Amadeus API** - Airline-direct pricing, real-time
- **Kiwi.com Tequila API** - Budget carriers, creative routing  
- **Google Flights** - Web scraping with Puppeteer
- **Skyscanner, Kayak, Momondo** - Stub modules ready to implement
- Automatic deduplication across sources
- Staggered requests with random delays to avoid rate limiting

### 2. **Deal Detection & Alerts**
- Automatic deal detection (price ≤ target)
- Email alerts with Gmail SMTP (nodemailer)
- Top 5 cheapest options included in email
- Direct booking links in alerts
- Configurable targets per destination

### 3. **Database & History**
- SQLite database (`data/flights.db`)
- Persistent across runs
- Three tables:
  - `flights` - All search results
  - `deals` - Prices below target
  - `price_history` - Trends over time
- Historical data for trend analysis

### 4. **GitHub Actions Automation**
- Runs every 4 hours automatically (00:00, 04:00, 08:00, 12:00, 16:00, 20:00 UTC)
- Full workflow: search → store → detect → alert → report → deploy
- Database committed back to repo for persistence
- Zero maintenance - fully automated

### 5. **Live Dashboard**
- Mobile-responsive HTML dashboard
- Deployed to GitHub Pages (free)
- Shows current cheapest prices per destination
- Deal highlights (green cards for under-target)
- Statistics summary
- Last updated timestamp
- Direct access from phone anytime

### 6. **Daily Reports**
- Auto-generated markdown reports
- Saved to `/reports/` directory
- Top 10 deals found
- Categorized by region
- Source attribution
- Emailed optional

### 7. **Configuration-Driven**
- Edit `config.json` to customize without touching code
- Add/remove destinations easily
- Change target prices anytime
- Enable/disable sources
- Adjust date ranges
- Toggle email alerts

### 8. **Modular Architecture**
- Each flight source in separate module (`src/sources/`)
- Easy to add new sources
- Database abstraction layer (`src/db/`)
- Utilities for scraping, email, reports, dashboard
- Main orchestrator coordinates everything

## 🚀 Getting Started

### For GitHub Actions Deployment:

1. **Create GitHub Secrets:**
   - AMADEUS_CLIENT_ID
   - AMADEUS_CLIENT_SECRET
   - KIWI_API_KEY
   - EMAIL_USER
   - EMAIL_PASSWORD

2. **Enable GitHub Pages:**
   - Settings → Pages → Source: GitHub Actions

3. **Trigger First Run:**
   - Actions tab → Flight Deal Tracker → Run workflow

4. **View Dashboard:**
   - https://yourusername.github.io/repo-name/

See **SETUP.md** or **DEPLOYMENT.md** for detailed steps.

### For Local Testing:

```bash

cp .env.example .env
# Add API keys to .env

```

## 🔄 Workflow Schedule

**Automatic runs every 4 hours:**
- 00:00 UTC
- 04:00 UTC
- 08:00 UTC
- 12:00 UTC
- 16:00 UTC
- 20:00 UTC

**Each run:**
1. Searches all enabled sources (~2-5 min)
2. Saves results to database
3. Detects deals (price ≤ target)
4. Sends email if deals found
5. Generates daily report
6. Builds dashboard
7. Commits changes
8. Deploys to GitHub Pages

## 🗄️ Database Schema

### flights table
```sql
id, timestamp, source, origin, destination,
departureDate, returnDate, price, pricePerPerson,
currency, airline, stops, totalHours, bookingUrl, passengers
```

### deals table
```sql
id, timestamp, origin, destination, departureDate,
returnDate, price, pricePerPerson, targetPrice, source,
percentBelowTarget, bookingUrl, emailSent, emailSentAt
```

### price_history table
```sql
id, timestamp, origin, destination, departureDate,
returnDate, minPrice, avgPrice, maxPrice,
sourceWithLowest, sourceCount
```

## 🎓 How to Extend

### Add a New Flight Source

1. Create `src/sources/new-source.js`
2. Implement `searchAllRoutes()` function
3. Export `source` object with `name`, `displayName`, `searchAllRoutes`
4. Add to `config.json` enabled array
5. Done! Next run uses new source

### Customize Dashboard

Edit `src/utils/dashboard-generator.js` to change:
- Colors & styling
- Which metrics shown
- Layout and sections

### Add Custom Logic

Modify `src/index.js` main() function to:
- Add additional analysis
- Change alert conditions
- Integration with other services
